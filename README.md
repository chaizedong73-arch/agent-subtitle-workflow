# 音视频字幕提取：给 AI agent 的工作流

把音频、视频或原始链接交给你的 AI，让它优先获取已有字幕，必要时识别语音，最后把文字展示出来或保存为文件。

这是一个 **AI 工作流 / Skill**，不是网站、桌面软件，也不附带转写模型。它告诉 agent 如何处理任务；实际能做什么，取决于你的 agent 是否能读取媒体、使用浏览器、运行工具或连接转写服务。只有文字聊天能力的 AI，不能靠这份说明直接听音频。

## 零基础怎么用

1. **准备输入**：一个音视频文件，或你有权访问的原始视频链接。先拿几十秒到一分钟的小片段试跑，避免整段处理后才发现效果不合适。
2. **把工作流交给 AI**：让 agent 读取本仓库的 [SKILL.md](SKILL.md)。如果它支持安装 Skill，可按它自己的安装方法安装；不支持也可以读取文件后照流程执行，不必安装额外平台。
3. **说明想要的结果**：逐字稿、带时间轴的字幕，或者二者都要；选择直接在聊天里看，或保存到自己指定的位置。
4. **先选转写方式，再开始**：agent 应解释需不需要安装、下载模型、上传文件或付费，并根据你的选择处理。
5. **检查结果**：听一小段原音，核对人名、术语、数字和时间轴。AI 识别可能出错，不能把它当成经过人工校对的字幕。

可以直接复制下面的话给 agent，替换方括号中的内容：

```text
请先阅读这个仓库的 README.md 和 SKILL.md，再按工作流处理。
输入：[附件或原始视频链接]
范围：[整段，或起止时间]
输出：[逐字稿 / SRT字幕 / 二者都要]
转写偏好：[先用已有字幕；需要ASR时优先本地Whisper / 可考虑云端 / 先帮我选]
预算：[不调用收费服务 / 最高可接受的金额]
结果：[直接在当前聊天展示 / 保存到我指定的文件夹]
在安装大文件、上传媒体或产生费用前，先说明具体方案和成本。
```

更多简短用法见 [examples.md](examples.md)。没有偏好时，agent 先检查已有字幕和可用工具，再解释最合适的下一步，不替你默认开通收费服务。

## 先认识几个词

| 词 | 简单解释 |
|---|---|
| 字幕 | 带有或不带有时间信息的视频文字；有时是作者提供，有时是机器生成 |
| ASR | 自动语音识别，把“听到的声音”变成文字，不是从画面里读字 |
| 逐字稿 | 尽量忠实记录说了什么；不是删减后的摘要 |
| SRT / VTT | 常见字幕文件格式，每段有开始时间、结束时间和文字 |
| 模型 | 负责识别声音的程序与参数；本地使用通常需要先下载 |
| API / 密钥 | 软件访问云服务的方式与凭证；密钥类似密码，不应写进聊天、公开笔记或仓库 |
| FFmpeg | 常见音视频处理工具，可抽取或转换音轨；不负责理解内容或转写 |

## 转写方式怎么选

| 方式 | 适合什么情况 | 费用与代价 |
|---|---|---|
| **已有字幕** | 平台、作者或你自己已经提供字幕 | 通常不新增ASR费用；访问权限或会员费用另算。字幕也可能有错 |
| **本地 Whisper** | 想减少云端上传，愿意在电脑上安装工具 | 开源版不按分钟收服务费，但要下载模型，占磁盘、内存、处理器时间和电力。普通CPU也能运行，但可能较慢；不是必须买显卡 |
| **本地 faster-whisper** | 想用Whisper体系的另一种实现，重视运行效率 | 同样有硬件、下载和安装成本；速度与兼容性依设备而变，不承诺固定提速 |
| **云端ASR** | 电脑较弱，或更看重少安装、服务端处理 | 通常需账号与密钥，可能按时长或其他单位计费；需要把音频传给服务商。免费额度、保存政策和地区限制要看当前官方说明 |
| **agent已有的音频工具** | 当前产品本身就支持转写 | 先核实它确实支持转写、额度和收费方式，不能因为能聊天就假定它能听音频 |

**Whisper开源版和名为“Whisper”的云端接口不是同一收费方式。** 本地Whisper不用购买某个云端API，但仍有本机资源成本。安装方式、模型大小与要求请以 [Whisper官方仓库](https://github.com/openai/whisper) 为准；替代实现见 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)。本仓库没有捆绑这些工具，也不自动安装它们。

云服务价格会变，本仓库不写死金额。agent 应先报告媒体时长、当前计费单位、单价来源和估计总额，再处理；按时长计费时可粗算为“需要识别的时长 × 单位时长价格”。最低计费单位、重试、其他模型调用和你的agent套餐费用还需单独计入，不能把所有服务都套成同一公式。

### 一、ASR 模型是什么

ASR（Automatic Speech Recognition，自动语音识别）是**专门把声音变成文字**的一类模型。输入是音频，输出是字符序列，内部大致做三件事：

1. **声学建模** —— 每一小段声音对应什么发音；
2. **语言建模** —— 结合上下文判断更可能是哪个词（同音字、术语、人名）；
3. **对齐** —— 每个字落在哪段时间上（要 SRT 时间轴就靠这一步）。

它**只做转写**：不总结、不解释、不判断语气，也不认识画面。

### 二、它和多模态"能听语音"的大模型不是一类东西

两者都"能处理声音"，但目的和计价逻辑完全不同：

| | 专用 ASR 模型 | 多模态大模型（带音频输入） |
|---|---|---|
| 主要任务 | 只把声音变成字 | 听 + 理解 + 回应，转写只是其中一项能力 |
| 计费单位 | **按音频时长**（分钟 / 小时） | **按 token**（音频会折算成 token） |
| 单价量级 | 批量转写每小时几毛到几块人民币 | 折算后通常明显更高，长音频差距更大 |
| 时间轴 | 多数能出 | 通常不保证 |
| 适合 | 只要一份逐字稿 | 要总结、翻译、追问、判断情绪 |
| 不适合 | 需要理解语义 | 把两小时录音整段丢进去当转写工具 |

一句话：**做字幕用 ASR 模型；想让 AI 听懂并回应，才用多模态模型。** 后者顺手也能转写，但按它的计价方式，把长音频当转写工具用一般不合算。

（例外：有些厂商用多模态底座做了「转写专用版」，计费方式接近 ASR。这类要看具体产品，不能按系列名一概而论。）

### 三、性价比：先看计费形状，再看单价

下表是**公开报价的量级参考，截至 2026 年 10 月**，随时会变。

**云端专用 ASR · 批量转写（每音频小时，人民币）**

| 服务 | 量级 |
|---|---|
| 微软 MAI-Transcribe-2（批量） | ≈¥0.7 |
| 阿里云 录音文件识别 | ¥0.8 起 |
| 阿里百炼 Paraformer | ≈¥0.8 |
| 火山引擎 豆包 录音文件识别 | ≈¥0.85–1.0 |
| 腾讯云 录音文件识别（大模型版） | ≈¥1.2–2.4 |
| 百度智能云 语音识别 | ≈¥1.5–3.0 |
| OpenAI Whisper API | ≈¥2.4（$0.006/分钟） |
| 科大讯飞 语音转写 | ¥4.9 起 |

**实时流式普遍比批量贵数倍。** 同一家的例子：微软流式版约 ¥3.6/小时，是自家批量版（¥0.67）的 5.4 倍——多付的钱买的是"听到约 100 毫秒就出字"。

**按分钟口径**（海外常用）：字节 seed-asr 约 $0.002/分钟，阿里 paraformer / qwen3-asr 约 $0.002–0.0021，gpt-4o-mini-transcribe 约 $0.0031，whisper-1 为 $0.006。中文档位整体比英文便宜约三倍。

**本地开源**：不按分钟计费，一次性下载模型，之后只花电和机器时间。代价是安装、磁盘、内存和速度，效果取决于模型大小与硬件。

### 四、按场景怎么选

| 你的情况 | 建议 |
|---|---|
| 一次性、几小时以内、机器一般 | 云端批量接口，最省事 |
| 经常用、量大、在意隐私 | 本地开源模型，装一次长期用 |
| 要实时字幕 / 边听边出字 | 才考虑流式，别为不需要的延迟付溢价 |
| 只要文字 | 不要用多模态大模型，单价差一个量级 |
| 要 AI 听完再总结 / 翻译 / 追问 | 多模态模型，或"先转写、再交给文本模型"两步走（通常更便宜） |
| 中文内容为主 | 国内厂商的批量档价格优势明显，中文识别是主场 |

**两条通用提醒**

1. **先量再算**：先拿到音频时长，再套"时长 × 单价"。免费额度不等于无限免费。
2. **准确率在干净语音上区分度很小**，真正拉开差距的是口音、噪声、中英混说和专业术语。**用自己的样本试一分钟**，比任何排行榜都准。

> 与上一节的关系：上一节说"本仓库不写死金额"仍然成立——本节的数字只用于判断量级和趋势；agent 向用户报账时**必须查当时的官方价**，不能直接引用本节。

## 中间会发生什么

**检查已有字幕 → 必要时取得音轨 → ASR → 核对 → 展示或保存。**

- 有可用字幕就先用，明确标注来源，不重复付费识别。
- 只有链接时，需要agent能访问相应页面或合法获取媒体；拿不到时请你提供文件或字幕，不假装读过内容。
- 部分工具能直接读取视频，不必先提取音频。确实需要音轨时再使用FFmpeg等工具，保留原文件，不覆盖。
- 长文件超过工具限制时可分段；记录分段起点，合并字幕时恢复原始时间轴，避免每段都从零开始。
- 听不清的地方标记“听不清”或“待核对”；整理稿和原始识别稿分开保存，不用猜测补全。
- SRT需要真实分段时间。如果工具只有纯文字，agent 不能凭字数编造时间轴；可先交付逐字稿，再说明补字幕需要支持时间戳的工具。

### 那个脚本做什么

`scripts/asr_pipeline.py` 只做一件事：**输入一个链接或本地文件，输出一个 txt**。

它不写笔记、不碰任何知识库、不依赖特定目录结构。相反，它集中在几个**真正容易出问题的地方**：

- 单段音频切多长（240 秒 / 段，段间冷却，长视频才不会中途崩）；
- 关掉模型的"思考"步骤（转写任务不需要推理，开着白烧 40% 的 token）；
- 子进程不要用 `text=True`（curl 的报错走系统代码页，按 UTF-8 解码会把真实错误吞成空串）；
- 429 与连接失败分别退避重试；
- 抽音频的格式（16k / 单声道 / 16bit），以及为什么不用 `-acodec copy`。

**它不是必须的。** 你的 agent 已经有转写工具，直接用那个更好；这份脚本的价值主要在**这些坑**——换成别的实现，坑还是那些坑。

### 它不替你做决定

脚本跑完只给一段纯文本，**要不要做术语纠错、要不要生成时间轴、要不要写进笔记，都不在它的职责内**。这些按你的实际需要单独处理，见下面几节。

## 一种实际在用的方式：手机刷到就丢给 AI

作者平时是这么用的——**手机刷视频，看到值得留的，直接把链接丢给电脑上的 AI，字幕在本地生成好。**

```
手机刷到视频
  → 分享链接到微信（或任何能发消息给 agent 的通道）
  → 电脑上的 agent 收到，跑一次转写
  → 结果回给你，或存到你指定的位置
```

好处是不用开电脑、不用记链接、不用攒到晚上再处理。刷完一圈回头看，字幕已经都在了。

**三个前提，缺一个就跑不通：**

- agent 常驻在一台**能跑脚本的电脑**上，且当时开着机；
- 手机和这个 agent 之间有一条**能发文字消息**的通道；
- agent 能访问那个链接（公开视频没问题；需要登录、或只在 App 内可见的内容，可能拿不到）。

**这不等于"必须用微信"。** 任何能把消息送到 agent 的通道都可以：企业微信、QQ 机器人、Telegram bot、飞书、邮件，甚至给自己发一条待办、让 agent 定时去取。**关键是"手机 → agent"这一跳要短**，短到你愿意在看到视频的那一秒就发出去。

⚠️ 一个副作用要提前想清楚：这类通道会让 agent **直接处理你转发的任何链接**。如果你的 agent 有执行任意命令的权限，建议加一条白名单（只处理指定域名），否则等于长期给它开着"访问任意 URL 并运行下载器"的权限。

## 结果放哪里

**直接在agent界面查看**：适合临时阅读或短片段。长稿应先说明篇幅，分段展示或在工具支持时生成附件，不只显示一个摘要就声称交付了全文。

**保存成自己的笔记或文件**：适合长期复用。可保存TXT、Markdown、SRT或VTT，位置由你决定。普通文件夹、Notion、Obsidian及其他笔记工具都可选；不要求使用某一种知识库或目录结构。写入外部笔记服务需要相应工具和你的授权。

> **下面这句很重要**：作者本人的习惯是把字幕直接导进自己的笔记软件，但**那只是一个人的用法，不是推荐做法，更不是唯一做法**。
> 你可能是：只要一个 txt 放桌面、要一份 SRT 交给剪辑软件对齐画面、要一段摘要直接发群、要按关键词批量检索几年前的录音、要喂给另一个模型做二次加工……**先说清楚你要的结果，让 agent 按你的目标选路径**。照搬别人的落点是这类工作流最常见的浪费。

推荐保留：标题、原始链接或文件说明、处理范围、字幕来源/转写方式、原始识别稿、需要核对的内容。不要为了做笔记额外上传私人媒体或密钥。

## 遇到问题

| 现象 | 下一步 |
|---|---|
| AI说不能读取链接或附件 | 先确认工具能力，改给可读取的媒体文件或已有字幕；换提示词不能凭空增加工具 |
| 本地运行太慢或内存不足 | 先缩短样本、选较小模型；若愿意上传和付费，再考虑云端 |
| 下载、安装失败 | 请agent解释具体错误和当前系统要求，不照抄别人的本机路径，也不要无限重试 |
| 字幕遗漏或术语错误 | 对照原音核查，必要时调整语言或换转写方案；保留原稿 |
| 没有时间轴 | 先交付文字，选择支持时间戳的工具后再生成字幕 |
| 云服务失败或额度不足 | 确认错误与是否已计费，保留已成功片段，不盲目重复整段请求 |

## 本体边界

核心只做字幕获取、音频转写、必要校对及交付。照片分析、视频画面OCR、内容总结、翻译、自动同步知识库都不是必须步骤，只有你明确提出时才另外安排。

不要绕过登录、付费或版权访问限制。云端上传前确认你愿意把该媒体发送给指定服务商；使用私人内容时优先考虑本地方案。

这份发布版只包含通用指令和示例，没有账户、密钥、本机路径、私人素材或额外模组。已检查Skill结构、内部链接和发布内容；未随仓库附带真实媒体，也不声称在所有agent和所有ASR服务上都已实测。
